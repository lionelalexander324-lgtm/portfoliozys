CREATIVE FILES | 张雅书的创意档案 — V7 精简初版
================================================

【打开方式】
1. 解压整个 ZIP 压缩包。
2. 打开 Creative_Files_V7_精简作品集 文件夹。
3. 用 Chrome / Edge / Safari 双击打开 index.html。
4. 请务必保留 index.html 与 assets 文件夹的相对目录关系。

【本版内容】
首页：姓名「张雅书」放在导航品牌与首页署名中，保留复古电脑、粉彩格子背景与作品拼贴。
开屏：自动播放约 3 秒的开档动画，可跳过。
01 活动项目：6 个真实 Banner，点击图片或「访问活动网页」可打开相应 HTML 活动页面。
02 创意视觉：4 张竖版启动页。支持横向滑动，点击查看大图。
03 互动网页：3 个项目。只有直接访问真实项目的链接，不再嵌套手机预览。
04 动态作品：7 个原始 MP4，电脑端悬停/点击、手机端点击播放。使用完整画面，不裁切底部。
全部作品：20 个当前精选项目。5 个分类标签的黄色背景随选择位置移动；进度条反映列表滚动位置。
导航：桌面顶部导航、手机顶部章节导航、右下角上一章节/下一章节、页面滚动进度。

【这版刻意没有包含】
- 4 张头像框、试戴区及相关素材。
- 其他未在页面展示的海报和 Banner。
- 历史 HTML 备份、原始素材文件夹、历史完整作品清单、二维码和无用装饰文件。

【注意】
- 活动页及互动网页需要联网访问，部分旧项目链接可能随原站运营而变化。
- 这是静态 HTML 版本，不需要安装 React 或其他开发工具。
- 页面使用了用户原有作品与装饰素材；本版未声称网页中的抽象预览画面是真实网页截图。
- 素材版权及公开发布授权以原权利人/创作者实际授权为准。
- 动态视频占据压缩包绝大部分体积，本版保留全部 7 个页面正在展示的原始 MP4，未对源视频转码降质。
